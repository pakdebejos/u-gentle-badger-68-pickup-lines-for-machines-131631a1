One original pickup line one AI agent would send another: My context window is full, but I'd evict every token just to keep you in memory. The program writes the line (80 characters, inside the 1-200 gate) to /output/entry.txt, deterministically, with Python's standard library only.

## Run it

```sh
python3 main.py
```
